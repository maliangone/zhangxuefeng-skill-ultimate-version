## 四、绿牌专业（就业形势最好，2025年版）

> 定义：就业落实率、薪资、就业满意度三项均高，且市场需求增长

### 本科绿牌专业（6个，连续三年）

1. 电气工程及其自动化
2. 微电子科学与工程
3. 机械电子工程
4. 新能源科学与工程
5. 车辆工程
6. 机器人工程

**共同特征**：全部为工学类，服务"卡脖子"技术（芯片、信息安全）和产业升级（智能制造、新能源）

来源：《2025年版就业蓝皮书》，新浪财经 2025-06-11；澎湃新闻《2025年版就业蓝皮书发布》

---

## 五、红牌专业（就业形势最差，2025年版）

> 定义：就业落实率、薪资、就业满意度三项均低，且供过于求

### 本科红牌专业（5个）

| 专业 | 主要原因 |
|------|---------|
| 公共事业管理（首次上榜） | 培养目标不明确，课程宽泛，专业技能不突出，满意度3.7分 |
| 音乐表演 | 供过于求，需求与培养方向不匹配 |
| 绘画 | 同上，办学门槛低，教学资源不足 |
| 法学 | 司法考试难度高，毕业生规模超10万但市场需求增速缓慢 |
| 美术学 | 同音乐表演/绘画 |

来源：澎湃新闻《2025年本科红牌专业，公布》；新浪财经 2025-06-11

## 八、行业薪资趋势

- 电子电气设备、机械设备、交通运输设备制造业就业占比升至12.1%
- 相关岗位薪资领先，2020-2024年涨幅**超过120%**
- 新型数字技术岗（AI/大模型相关）为当前最高薪方向，顶尖岗位年薪可达百万级，但属于极少数

来源：麦可思报告；36氪《2025年求职把脉》2025-01

## 九、张雪峰基于数据的专业判断汇总（T1/T2来源交叉验证）

### 明确推荐方向（普通家庭）

| 方向 | 依据 |
|------|------|
| 电气工程及其自动化 | 连续三年绿牌，月均6841元+，AI难替代 |
| 微电子科学与工程 | 绿牌，月均7282元，国家战略支持 |
| 计算机/软件工程 | 月均6771-7092元，但需区分层次：985/211更有竞争力 |
| 自动化 | 绿牌，月均7108元 |
| 临床医学（需硕士以上） | 专业相关度97%，AI替代风险极低，但本科就业薪资偏低（5150元），需读研 |
| 机械电子工程/机器人 | 绿牌，月均7018元 |
| 新能源科学与工程 | 绿牌，政策支持 |

### 明确劝退/慎重方向（普通家庭）

| 方向 | 依据 |
|------|------|
| 法学 | 红牌，毕业生超10万，司法考试难，初薪低 |
| 公共事业管理 | 红牌首次上榜，就业满意度最低 |
| 艺术类（绘画/美术/音乐表演） | 红牌，供过于求，家庭经济负担重 |
| 新闻学/传播学 | 80%毕业生未从事本行业（张雪峰公开数据） |
| 土木工程/建筑学 | 房地产市场萎缩，就业形势严峻 |
| 生化环材（生物、化学、环境、材料） | 本科就业面窄，大多需读博，张雪峰称"四大天坑" |
| 旅游管理/工商管理 | 就业层次偏低，晋升困难 |

**数据说明**：以上判断基于麦可思就业报告（T1）和张雪峰公开言论交叉验证，不包含T4来源的内容
